# Security Policy

Security fixes are supported for the latest release on a best-effort basis while the
project is in alpha.

Report vulnerabilities using GitHub's private vulnerability reporting for
`joshuamyers22/data-mcp`. If that option is unavailable, contact the maintainer
privately through the contact method on the maintainer's GitHub profile. Do not open
a public issue before a fix or mitigation is available.

Include the affected version, source type, configuration shape with secrets removed,
impact, reproduction steps, and any suggested mitigation. Never include working
credentials, access tokens, private object keys, or production data.

You should receive an acknowledgement within seven days. Remediation and disclosure
timing depend on severity and maintainer availability. This policy is not a warranty
or service-level agreement.
